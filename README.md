# Elite Lawns & Landscaping — Version 11

Production-ready static website.

## Upload
Upload the contents of this folder to the repository root, replacing the current website files. Keep the same folder structure.

## Important
The canonical URL, structured data, robots.txt and sitemap.xml currently use:
https://elitelawns.co.nz/

If the live domain is different, replace that domain in index.html, robots.txt and sitemap.xml before publishing.

## Included
- Responsive index.html
- Local images in assets/images
- styles.css and script.js
- favicon.png
- sitemap.xml
- robots.txt
- SEO and LocalBusiness structured data
- FormSubmit contact form
